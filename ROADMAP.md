# Baque Facil Roadmap

Items are listed in priority order, highest first.

1. Add images or animations for the signals mestres use to call the next rhythm.
2. Radio: add a whistle as an instrument for transitions.
3. Radio: show signals and whistles while hiding notes so users can practice associating each signal with its rhythm.
4. Add new rhythm: convencao 2 from martelo.
5. Add new rhythm: convencao 1 from martelo.
6. Add new rhythm: marcacao transition.
7. Add new rhythm: pao com manteiga.
8. Composer: add a way to add built-in instruments besides alfaia.
9. Add a popup asking users if they want to install the app on iOS, Android, Windows, macOS and Linux, with installation instructions when a native install prompt is unavailable.
10. Revisit how users set up offline mode. Consider asking on their first visit whether they want to make the app available offline.
